# demo/

The demo video and the PDF deck for SkyStay:

- `SkyStay_demo.mp4`: a 98-second walkthrough of the working simulator
- `SkyStay_deck.pdf`: a 10-page overview of the problem, method, results and limitations

Both files are generated by `skystay video` and `skystay deck` from pipeline outputs and copied here only after they pass their checks.
