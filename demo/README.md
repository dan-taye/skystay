# demo/

The demo video and the PDF deck for SkyStay:

- `SkyStay_demo.mp4`: a 98-second walkthrough of the working simulator (placeholder synthetic voiceover)
- `SkyStay_deck.pdf`: a 10-page overview of the problem, method, results and limitations

Both are generated from the pipeline's outputs by `skystay video` and `skystay deck`. All figures are on synthetic demo data.
